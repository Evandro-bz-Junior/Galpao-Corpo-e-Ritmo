## 🌍 Galpão Corpo e Ritmo
Bem-vindo ao Galpão Corpo e Ritmo, um site fictício de um espaço de fitness e dança desenvolvido como projeto acadêmico para praticar habilidades de desenvolvimento front-end.

## 💡 Visão Geral
O Galpão Corpo e Ritmo é um portal fictício que apresenta atividades físicas, ritmos de dança, serviços oferecidos e informações de contato de forma simples, moderna e responsiva. O projeto tem como objetivo praticar boas práticas de desenvolvimento web.

## Objetivos do Projeto:
-Consolidar conhecimentos em HTML5, CSS3/SCSS e JavaScript.

-Criar um site responsivo e visualmente atraente.

-Explorar deploy com Vercel.

## 🧰 Tecnologias Utilizadas

- HTML5             # Estrutura do site
- CSS3/SCSS         # Estilização e design responsivo
- JavaScript        # Interatividade no site
- Vercel            # Hospedagem e deploy

## 📁 Estrutura do Projeto
Galpao-Corpo-e-Ritmo/
  - assets/
    - imgs/            # Imagens do site
    - scripts/         # Arquivos JavaScript
    - styles/          # Arquivos CSS/SCSS
  - index.html         # Página principal
  - README.md          # Documentação do projeto

  
## ⚙️ Como Rodar o Projeto Localmente
Siga os passos abaixo para executar o projeto em sua máquina:

-Clone o repositório:   
   git clone https://github.com/Evandro-bz-Junior/Galpao-Corpo-e-Ritmo.git   
-Acesse a pasta do projeto:   
   cd Galpao-Corpo-e-Ritmo   
-Abra o site no navegador:   
   Método rápido: Clique duas vezes no arquivo index.html para abri-lo diretamente no navegador.   
   Método recomendado: Use a extensão Live Server no VSCode para rodar o site localmente com recarregamento automático.
